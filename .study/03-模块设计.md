# IronClaw 模块设计文档

## 1. 模块架构概述

IronClaw采用模块化架构，每个模块负责特定的功能领域。模块之间通过清晰的接口进行通信，保持低耦合高内聚。

## 2. 核心模块详解

### 2.1 Agent 模块

**位置**: `src/agent/`

**职责**:
- 协调所有组件完成用户请求
- 管理任务生命周期
- 实现会话和对话管理
- 提供自修复能力

**主要组件**:

| 组件 | 文件 | 职责 |
|------|------|------|
| Agent | agent_loop.rs | 主代理循环，消息处理协调 |
| Router | router.rs | 意图分类和路由 |
| Scheduler | scheduler.rs | 任务调度和资源分配 |
| Worker | worker.rs | 任务执行和工具调用 |
| SessionManager | session_manager.rs | 会话生命周期管理 |
| Session | session.rs | 单个会话状态管理 |
| UndoManager | undo.rs | 撤销/重做功能 |
| ContextCompactor | compaction.rs | 上下文压缩 |
| HeartbeatRunner | heartbeat.rs | 心跳检查执行 |
| RoutineEngine | routine_engine.rs | 自动化任务引擎 |
| SelfRepair | self_repair.rs | 自修复逻辑 |
| JobMonitor | job_monitor.rs | 任务监控 |
| CostGuard | cost_guard.rs | 成本监控和限制 |

**关键接口**:
```rust
pub trait Agent {
    async fn handle_message(&self, message: IncomingMessage) -> Result<AgentResponse>;
    async fn create_job(&self, description: String) -> Result<Uuid>;
    async fn cancel_job(&self, job_id: Uuid) -> Result<()>;
}

pub trait Router {
    async fn classify_intent(&self, message: &str) -> Result<MessageIntent>;
}

pub trait Scheduler {
    async fn schedule(&self, task: Task) -> Result<Uuid>;
    async fn cancel(&self, task_id: Uuid) -> Result<()>;
}

pub trait Worker {
    async fn execute(&self, job: Job) -> Result<JobOutput>;
}
```

**数据流**:
```
IncomingMessage → Router → Intent → Scheduler → Worker → Tool Calls → Response
                     ↓
                 Session Manager
                     ↓
                 Context Manager
```

```rust
pub trait LlmProvider: Send + Sync {
    fn model_name(&self) -> String;

    async fn complete(&self, request: CompletionRequest) -> Result<CompletionResponse>;

    async fn complete_with_tools(
        &self,
        request: ToolCompletionRequest,
    ) -> Result<ToolCompletionResponse>;

    async fn stream(&self, request: CompletionRequest) -> ResponseStream;

pub trait CompletionRequest {
    fn messages(&self) -> &[ChatMessage];
    fn tools(&self) -> &[ToolDefinition];
    fn system_prompt(&self) -> &str;

    fn content(&self) -> &str;

    fn finish_reason(&self) -> &FinishReason;
    fn usage(&self) -> &TokenUsage;
}
```
