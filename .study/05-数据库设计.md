# IronClaw 数据库设计文档

## 1. 数据库概述

IronClaw使用关系型数据库存储所有持久化数据，支持PostgreSQL（默认）和libSQL（嵌入式）两种后端。

### 1.1 数据库特性

**PostgreSQL** (默认):
- 生产级关系型数据库
- 支持pgvector扩展用于向量搜索
- 完整的ACID事务支持
- 高并发性能

**libSQL** (嵌入式):
- 轻量级嵌入式数据库
- SQLite兼容
- 适合单机部署
- 支持远程复制

### 1.2 扩展依赖

**必需扩展**:
- `pgvector`: 向量相似度搜索

**安装命令**:
```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

## 2. 核心表设计

### 2.1 对话表 (conversations)

**用途**: 存储用户对话会话

**表结构**:
```sql
CREATE TABLE conversations (
    id UUID PRIMARY KEY,
    channel TEXT NOT NULL,
    user_id TEXT NOT NULL,
    thread_id TEXT,
    started_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    last_activity TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    metadata JSONB NOT NULL DEFAULT '{}'
);
```

**字段说明**:

| 字段 | 类型 | 约束 | 说明 |
|------|------|----------|------|
| id | UUID | PRIMARY KEY | 对话唯一标识 |
| channel | TEXT | NOT NULL | 通道类型 (repl, http, telegram等) |
| user_id | TEXT | NOT NULL | 用户标识 |
| thread_id | TEXT | NULLABLE | 线程ID (可选) |
| started_at | TIMESTAMPTZ | NOT NULL | 对话开始时间 |
| last_activity | TIMESTAMPTZ | NOT NULL | 最后活动时间 |
| metadata | JSONB | NOT NULL | 元数据 (键值对) |

**索引**:
```sql
CREATE INDEX idx_conversations_channel ON conversations(channel);
CREATE INDEX idx_conversations_user ON conversations(user_id);
CREATE INDEX idx_conversations_last_activity ON conversations(last_activity);
```

```sql
CREATE TABLE memory_documents (
```

### 3.2 记忆分块表 (memory_chunks)

**用途**: 存储文档的分块，用于混合搜索

**表结构**:
```sql
CREATE TABLE memory_chunks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    document_id UUID NOT NULL REFERENCES memory_documents(id) ON DELETE CASCADE,
    chunk_index INT NOT NULL,
    content TEXT NOT NULL,
    content_tsv TSVECTOR GENERATED ALWAYS AS (to_tsvector('english', content)) STORED,
    embedding VECTOR(1536),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    CONSTRAINT unique_chunk_per_doc UNIQUE (document_id, chunk_index)
);
```

**字段说明**:

| 字段 | 类型 | 约束 | 说明 |
|------|------|----------|------|
| id | UUID | PRIMARY KEY | 分块唯一标识 |
| document_id | UUID | FK, NOT NULL | 所属文档 |
| chunk_index | INT | NOT NULL | 分块索引 |
| content | TEXT | NOT NULL | 分块内容 |
| content_tsv | TSVECTOR | GENERATED | 全文搜索向量 |
| embedding | VECTOR(1536) | NULLABLE | 语义搜索向量 |
| created_at | TIMESTAMPTZ | NOT NULL | 创建时间 |

**索引**:
```sql
CREATE INDEX idx_memory_chunks_tsv ON memory_chunks USING GIN(content_tsv);
CREATE INDEX idx_memory_chunks_embedding ON memory_chunks
    USING hnsw(embedding vector_cosine_ops)
    WITH (m = 16, ef_construction = 64);
CREATE INDEX idx_memory_chunks_document ON memory_chunks(document_id);
```

## 4. 安全表设计

### 4.1 密钥表 (secrets)

**用途**: 加密存储用户凭证

**表结构**:
```sql
CREATE TABLE secrets (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id TEXT NOT NULL,
    name TEXT NOT NULL,
    encrypted_value BYTEA NOT NULL,
    key_salt BYTEA NOT NULL,

    usage_count BIGINT NOT NULL DEFAULT 0,

);
```

**字段说明**:

| 字段 | 类型 | 约束 | 说明 |
|------|------|----------|------|
| id | UUID | PRIMARY KEY | 密钥唯一标识 |
| user_id | TEXT | NOT NULL | 用户ID |

| key_salt | BYTEA | NOT NULL | 密钥派生盐值 (HKDF) |
| provider | TEXT | NULLABLE | 提供商 |
| expires_at | TIMESTAMPTZ | NULLABLE | 过期时间 |
| last_used_at | TIMESTAMPTZ | NULLABLE | 最后使用时间 |
| usage_count | BIGINT | NOT NULL | 使用次数 |
| created_at | TIMESTAMPTZ | NOT NULL | 创建时间 |
| updated_at | TIMESTAMPTZ | NOT NULL | 更新时间 |

**索引**:

## 9. 函数设计

### 9.1 列出工作空间文件函数

**用途**: 列出目录中的文件和子目录

**函数定义**:
```sql
CREATE OR REPLACE FUNCTION list_workspace_files(
    p_user_id TEXT,
    p_agent_id UUID,
    p_directory TEXT DEFAULT ''
)
RETURNS TABLE (
    path TEXT,
    is_directory BOOLEAN,
    updated_at TIMESTAMPTZ,
    content_preview TEXT
) AS $$
BEGIN
    -- 标准化目录路径
    IF p_directory != '' AND NOT p_directory LIKE '%/' THEN
        p_directory := p_directory || '/';
    END IF;

    RETURN QUERY
    WITH files AS (
        SELECT
            d.path,
            d.updated_at,
            LEFT(d.content, 200) as content_preview,
            -- 提取直接子项名称
            CASE
                WHEN p_directory = '' THEN
                    CASE
                        WHEN position('/' in d.path) > 0
                        THEN substring(d.path from 1 for position('/' in d.path) - 1)
                        ELSE d.path
                    END
                ELSE
                    CASE
                        WHEN position('/' in substring(d.path from length(p_directory) + 1)) > 0
                        THEN substring(
                            substring(d.path from length(p_directory) + 1)
                            from 1
                            for position('/' in substring(d.path from length(p_directory) + 1)) - 1
                        )
                        ELSE substring(d.path from length(p_directory) + 1)
                    END
            END as child_name
        FROM memory_documents d
        WHERE d.user_id = p_user_id
          AND d.agent_id IS NOT DISTINCT FROM p_agent_id
          AND (p_directory = '' OR d.path LIKE p_directory || '%')
    )
    SELECT DISTINCT ON (f.child_name)
        CASE
            WHEN p_directory = '' THEN f.child_name
            ELSE p_directory || f.child_name
        END as path,
        EXISTS (
            SELECT 1 FROM memory_documents d2
            WHERE d2.user_id = p_user_id
              AND d2.agent_id IS NOT DISTINCT FROM p_agent_id
              AND d2.path LIKE
                CASE WHEN p_directory = '' THEN f.child_name ELSE p_directory || f.child_name END
                || '/%'
        ) as is_directory,
        MAX(f.updated_at) as updated_at,
        CASE
            WHEN EXISTS (
                SELECT 1 FROM memory_documents d2
                WHERE d2.user_id = p_user_id
                  AND d2.agent_id IS NOT DISTINCT FROM p_agent_id
                  AND d2.path LIKE
                    CASE WHEN p_directory = '' THEN f.child_name ELSE p_directory || f.child_name END
                    || '/%'
            ) THEN NULL
            ELSE MAX(f.content_preview)
        END as content_preview
    FROM files f
    WHERE f.child_name != '' AND f.child_name IS NOT NULL
    GROUP BY f.child_name
    ORDER BY f.child_name, is_directory DESC;
END;
$$ LANGUAGE plpgsql;
```
